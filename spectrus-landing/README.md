# SPECTRUS — Landing Page (Next.js App)

Aplicación web desarrollada en **Next.js (App Router)** para la landing page de **SPECTRUS**.

Consulta el archivo principal de documentación [`../README.md`](../README.md) en la raíz del repositorio para detalles de arquitectura, assets, stack y guías completas.

## Scripts disponibles

```bash
npm run dev      # Servidor de desarrollo (http://localhost:3000)
npm run build    # Compilación de producción
npm run start    # Iniciar servidor de producción
npm run lint     # Validación de linter ESLint
```
